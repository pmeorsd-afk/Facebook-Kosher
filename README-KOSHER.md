## מה פייסבוק כשר עושה בפועל

**פייסבוק כשר** ממיר את תוסף הקוד הפתוח `Facebook-Plus` לגרסה ייעודית **דוברת עברית (`he-IL`, RTL)** במצב **סינון מחמיר כברירת מחדל (Strict Mode)** ובמצב **טקסט בלבד (Text-Only)**:

- **מצב מחמיר כברירת מחדל בהפעלה ראשונה:** תמונות, סרטונים, קבצי GIF, מדבקות, אודיו, רילס (Reels), סטוריז (Stories), Watch, שידורים חיים (Live), פיד אלגוריתמי כללי, פרסומות, המלצות, סקרים, חיפוש גלובלי וקישורים חיצוניים — כולם חסומים כברירת מחדל.
- **מצבי אי-ודאות (`UNKNOWN`) מתנהגים תמיד כחסימה (`BLOCK`):** אם יעד, דגם נתונים (`FBMemModelObject`) או כתובת אינם ניתנים לאימות מול רשימת ההיתרים — הגישה נחסמת אוטומטית.
- **מקורות מאושרים בלבד (Allowlist):** המנהל מגדיר רשימה מוגנת-PIN של מזהי קבוצות (`groupID`), מזהי עמודים (`pageID`), פרופילים אופציונליים ודומיינים חיצוניים מאושרים (כולל קידומת נתיב). אישור קבוצה אינו מאשר פרופילים של חברים, עמודים מקושרים, פוסטים משותפים ממקור לא-מאושר או קישורים חיצוניים.
- **מצב טקסט בלבד חוצה-אפליקציה:** חסימה בשכבות הרשת (`NSURLSession`), התצוגה (`UIImageView`, `AVPlayer`, `AVPlayerLayer`, `FBWebImageView`, `RCTImageView`, `FNFAVPlayer`, `FBVideoPlaybackController`), התוכן (`FBPKosherContentFilter`), הדפדפן הפנימי (`WKWebView` CSS+JS + `FBWebViewController`) וניקוי מטמון מדיה בעלייה למניעת הבהוב של תוכן ישן.
- **מסך בית עברי נקי (`פייסבוק כשר`):** מחליף את הפיד הכללי של פייסבוק במסך ניווט נגיש מימין לשמאל: **הקבוצות שלי**, **העמודים שלי**, **מועדפים**, **התראות**, **מרקטפלייס** (מוסתר ונעול עד לאימות מנהל), ו**הגדרות**.
- **חיפוש מאושר מקומי (`FBPKosherSearchGuard`):** מחפש אך ורק ברשימת המקורות המאושרים במכשיר; החיפוש הגלובלי של פייסבוק חסום.
- **מרקטפלייס חסום כברירת מחדל:** תשתית סינון JSON/Relay קיימת (`FBPKosherMarketplaceGuard`), אך הגישה חסומה כברירת מחדל עם ההודעה: `"מרקטפלייס אינו זמין במצב הסינון המחמיר."` עד לאימות מלא בגרסת היעד.
- **נעילת מנהל מבוססת Keychain + PBKDF2-HMAC-SHA256:** הגדרת קוד מנהל בן 6–16 ספרות, חסימת ניסיונות כושלים הדרגתית (rate limiting), וקוד שחזור חד-פעמי (Crockford Base32) ששומר על מצב הסינון המחמיר פעיל.
- **ניטור תאימות והשבתת כשל בטוחה (`FBPKosherCompatibilityMonitor`):** אם רכיב אכיפה קריטי חסר בגרסת הפייסבוק המותקנת, מוצג מסך נעילה בטוח עם ההודעה: `"לא ניתן להפעיל את הסינון בצורה בטוחה בגרסה זו של פייסבוק."` במקום חשיפת פייסבוק ללא סינון.

## הגדרת מנהל ושימוש שוטף

1. **הפעלה ראשונה:** האפליקציה עולה למסך הפתיחה בעברית ולמסך הבית הכשר (`FBPKosherHomeController`). בהעדר מקורות מאושרים מוצג מצב ריק עם גישה ישירה לניהול מנהל.
2. **הגדרת קוד מנהל:** ב**ניהול מנהל** (`FBPKosherAdminController`) יש לבחור קוד בן 6–16 ספרות. הקוד נשמר כגזור PBKDF2-HMAC-SHA256 עם Salt אקראי ב-iOS Keychain (ולעולם לא בטקסט גלוי ב-`NSUserDefaults`). מופק קוד שחזור חד-פעמי שיש לשמור במקום בטוח.
3. **הוספת מקורות מאושרים:** המנהל יכול להוסיף קבוצות, עמודים, פרופילים ודומיינים חיצוניים (לפי מזהה יציב או כתובת URL), לסמן **מועדפים**, לשנות שם תצוגה ידידותי, לחפש ברשימה ולייצא/לייבא JSON (ללא פרטי אימות או סיסמאות).
4. **משתמש רגיל:** אינו יכול לכבות את מצב הסינון המחמיר או לאפשר מרקטפלייס ממסך ההגדרות הרגיל (`FBPPrefs` דוחה כתיבה למפתחות המוגנים).

## לוקליזציה לעברית, דו-כיווניות (BiDi) ונגישות

- נוספה תיקיית תרגום מלאה [`Localizations/he.lproj/Localizable.strings`](Localizations/he.lproj/Localizable.strings) עם 369 מפתחות מסונכרנים מול כל 19 השפות בתוסף.
- [`src/Features/Language/FBPLanguageController.m`](src/Features/Language/FBPLanguageController.m) רושם את השפה העברית בקוד **`he`** (`עברית` / `Hebrew`) בנפרד מ-`hi` (`हिन्दी` / `Hindi`).
- כיווניות RTL מוחלת **אך ורק על תצוגות התוסף** (`FBPApplySemanticDirection`) כדי לא לשבש פריסות פנימיות של Facebook עצמו.
- מחרוזות לטיניות/מספרים/כתובות משובצות בעברית מבודדות באמצעות סמני Unicode LRI/PDI (`U+2066`..`U+2069`) דרך `FBPBidiIsolateLTR`.
- תמיכה מובנית ב-Dynamic Type (`FBPScaledFont`), ניגודיות גבוהה (`FBPKeyKosherHighContrast`), הפחתת תנועה (`FBPKeyKosherReducedMotion`), מטרות מגע מוגדלות ותוויות VoiceOver.

## דרישות מערכת, גרסאות נתמכות ובנייה

| רכיב | מצב |
|---|---|
| גרסת iOS מינימלית | iOS 14.0+ (על פי הגדרות `Makefile` ו-Theos) |
| גרסאות Facebook עם מפת הוקים מזוהה במטריצת התאימות | `570.*`, `574.*`, `578.*`, `585.*`, `586.*` (גרסה `587.*` מסווגת כחלקית; גרסאות לא מוכרות מסווגות `Unknown` ומחילות כשל בטוח) |
| סביבת בנייה נדרשת | **macOS / Linux עם Theos + Xcode/iOS SDK + `clang` + `perl` + `plutil`** |
| סטטוס בסביבה הנוכחית (Windows) | קוד המקור והבדיקות הסטטיות/לוגיות עברו; הידור בינארי `.deb`/`.dylib` ובדיקות על מכשיר ממתינים לסביבת Theos/macOS |

פקודות בנייה ואימות (בסביבת macOS / Linux + Theos):

```bash
# בדיקת תחביר והיגיינה
python3 scripts/verify.py test
python3 scripts/verify.py check
python3 test/test_kosher_verification.py

# הרצת בדיקות היחידה ב-Objective-C על סימולטור iOS (macOS)
make -C test/KosherTests test-sim

# בניית חבילות
python3 build.py --rootless
python3 build.py --rootfull
python3 build.py --roothide
python3 build.py --trollfools --ipa /path/to/decrypted_lawful_Facebook.ipa
```

> **מדיניות הפצה וקניין רוחני:** מאגר זה אינו כולל, אינו מארח ואינו מפיץ את קובץ ה-IPA הקנייני של Meta/Facebook, מפתחות חתימה או פרטי הזדהות. המשתמש מספק עותק חוקי משלו בלבד לצורך הזרקת התוסף במכשיר שבבעלותו.
